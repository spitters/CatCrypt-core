# FiatShamirROM: Σ-protocols and the Fiat–Shamir transform

`CatCryptCore/Crypto/FiatShamirROM/` states Σ-protocols and the Fiat–Shamir transform in the
random-oracle model and proves their security with concrete bounds. Every bound holds for every
adversary through an explicit reduction defined in the file, with its running time. The
namespace is `CatCrypt.Crypto.FiatShamirROM`.

The constructions of the CFRG drafts
[draft-irtf-cfrg-sigma-protocols-03](https://datatracker.ietf.org/doc/draft-irtf-cfrg-sigma-protocols/)
and [draft-irtf-cfrg-fiat-shamir-03](https://datatracker.ietf.org/doc/draft-irtf-cfrg-fiat-shamir/)
are proved here; the comparison with the drafts and the extracted implementation of the crate
`sigma-proofs` are described in the
[SigmaProtocol README of the CatCrypt repository](https://github.com/spitters/CatCrypt/blob/master/CatCrypt/Crypto/SigmaProtocol/README.md).

## What is proved

| Topic | What is proved |
|---|---|
| Σ-protocols | The interface [`Sigma`](https://github.com/spitters/CatCrypt-core/blob/main/CatCryptCore/Crypto/FiatShamirROM/Game.lean) with special soundness, perfect and statistical HVZK, completeness, unique responses and commitment min-entropy; a `Sigma` gives a protocol of `CatCrypt.Examples.Sigma` ([`toSigmaProtocol`](https://github.com/spitters/CatCrypt-core/blob/main/CatCryptCore/Crypto/FiatShamirROM/Bridge.lean)) |
| Fiat–Shamir signatures | EUF-CMA in the random-oracle model by the forking lemma ([`fiatShamir_rom_eufcma`](https://github.com/spitters/CatCrypt-core/blob/main/CatCryptCore/Crypto/FiatShamirROM/Reduction.lean)), with the signing oracle simulated under statistical HVZK and aborts ([`run_real_le_sim`](https://github.com/spitters/CatCrypt-core/blob/main/CatCryptCore/Crypto/FiatShamirROM/StatHVZK.lean)), straight-line extraction ([`fiatShamir_rom_eufcma_sl`](https://github.com/spitters/CatCrypt-core/blob/main/CatCryptCore/Crypto/FiatShamirROM/StraightLineCls.lean)), key recovery ([`KeyRecovery`](https://github.com/spitters/CatCrypt-core/blob/main/CatCryptCore/Crypto/FiatShamirROM/KeyRecovery.lean)) and the running times of the reductions ([`Timed`](https://github.com/spitters/CatCrypt-core/blob/main/CatCryptCore/Crypto/FiatShamirROM/Timed.lean)) |
| MPC-in-the-head | EUF-CMA of the Fiat–Shamir signatures of MPC-in-the-head proofs with all-but-one opening ([`Params.eufcma_le`](https://github.com/spitters/CatCrypt-core/blob/main/CatCryptCore/Crypto/FiatShamirROM/MPCitH.lean)) |
| Linear relations (draft-irtf-cfrg-sigma-protocols-03 §3–4) | The Σ-protocol [`linearSigma`](https://github.com/spitters/CatCrypt-core/blob/main/CatCryptCore/Crypto/FiatShamirROM/LinearRelation.lean) is complete, special sound with an explicit extractor and perfectly HVZK, and has unique responses for injective maps; the compact verifier accepts exactly the proofs the batchable verifier accepts ([`linearSigma_compactVerify_iff`](https://github.com/spitters/CatCrypt-core/blob/main/CatCryptCore/Crypto/FiatShamirROM/LinearRelation.lean)); AND composition by concatenation ([`holds_and_iff`](https://github.com/spitters/CatCrypt-core/blob/main/CatCryptCore/Crypto/FiatShamirROM/LinearRelation.lean)); dlog, DLEQ, Pedersen, Okamoto and ElGamal are instances, and Schnorr ([`schnorrSigma`](https://github.com/spitters/CatCrypt-core/blob/main/CatCryptCore/Crypto/FiatShamirROM/Schnorr.lean)) follows from the dlog instance |
| Fiat–Shamir for proofs (both drafts) | With session identifier and statement in the hash: knowledge soundness against adaptively chosen statements, ε(ε/(q+1) − 1/\|Ch\|) ≤ extraction probability, with the extractor's running time ([`ksExtractProb_ge`](https://github.com/spitters/CatCrypt-core/blob/main/CatCryptCore/Crypto/FiatShamirROM/NIZK.lean)); zero knowledge within qP·δ + qP·(qH+qP)·γ ([`zkReal_le_zkSim`](https://github.com/spitters/CatCrypt-core/blob/main/CatCryptCore/Crypto/FiatShamirROM/NIZK.lean)) |
| Duplex sponge and codecs (draft-irtf-cfrg-fiat-shamir-03 §3–6) | Absorb and squeeze laws ([`absorb_absorb`](https://github.com/spitters/CatCrypt-core/blob/main/CatCryptCore/Crypto/FiatShamirROM/DuplexSponge.lean)), prefix-free transcripts ([`prefixFree_absorbedTranscript`](https://github.com/spitters/CatCrypt-core/blob/main/CatCryptCore/Crypto/FiatShamirROM/DuplexSponge.lean)), decoding within 2^-128 of uniform at Ns + 16 bytes ([`tvDist_decodeUintDist_le_two_pow`](https://github.com/spitters/CatCrypt-core/blob/main/CatCryptCore/Crypto/FiatShamirROM/DuplexSponge.lean)), parsing that accepts exactly the serializations and rejects trailing bytes ([`Codec.parseAll_eq_some_iff`](https://github.com/spitters/CatCrypt-core/blob/main/CatCryptCore/Crypto/FiatShamirROM/DuplexSponge.lean)) |
| The duplex-sponge transform | Reduced to Fiat–Shamir for proofs with the decoding bias (qH+1)·M/256^L added, against adversaries that query the sponge at arbitrary byte strings, with the reduction's running time ([`dsRawKsExtractProb_ge`](https://github.com/spitters/CatCrypt-core/blob/main/CatCryptCore/Crypto/FiatShamirROM/DuplexSpongeRawOracle.lean)); zero knowledge with the oracle keyed by absorbed strings ([`dsRawZkReal_le_zkSim`](https://github.com/spitters/CatCrypt-core/blob/main/CatCryptCore/Crypto/FiatShamirROM/DuplexSpongeRawOracle.lean)) |
